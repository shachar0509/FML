# Installing Shalav

## Windows
1. Download `Shalav_<version>_x64-setup.exe` from the release page.
2. Run it. If "Windows protected your PC" appears, click **More info**, then **Run anyway**.
3. Shalav installs for your user (no admin rights needed) and opens.

## macOS
1. Download `Shalav_<version>_universal.dmg`.
2. Open it and drag Shalav to Applications, then open Shalav.
3. When macOS says it can't verify the app, click **Done**. Open **System Settings → Privacy & Security**, scroll to the Shalav message, click **Open Anyway** and confirm. This is needed only once.

## First launch
1. Choose a language.
2. Create an Anthropic API key at console.anthropic.com (Settings → API keys), and set a monthly spend limit in the console (Settings → Limits). Paste the key into Shalav and press **Check key**. It is stored in your system keychain only.
3. Choose where Shalav keeps its data folder.
4. Google Drive sync is optional. You can connect it later in Settings → Sync.

## Updates
Shalav updates itself. When a new version is available, press **Update and restart**.
